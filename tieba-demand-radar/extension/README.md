# 贴吧需求雷达采集助手（Chrome 扩展）

## 用途
使用你自己 Chrome 浏览器中已经登录的百度贴吧会话，搜索指定贴吧和关键词，读取搜索结果与帖子正文，筛选求助类帖子，并导出 JSON。扩展不收集百度密码、Cookie、验证码，不代替用户登录，不绕过访问限制。

## 安装
1. 在电脑 Chrome 打开 `chrome://extensions`（扩展程序）。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本目录 `extension`。
5. 在同一个 Chrome 浏览器打开贴吧并完成登录。
6. 点击工具栏的「贴吧需求雷达采集助手」，设置贴吧与关键词，点击「开始扫描已登录贴吧」。
7. 扫描结束后点击「导出需求数据 JSON」。
8. 打开需求雷达网页，在「需求池」使用「导入 JSON」恢复备份入口目前接受标准数据结构；若导入格式不匹配，可先将 JSON 内容复制到批量导入区域，或使用扩展导出数据再做适配。

## 限制
- 当前扩展面向桌面 Chrome/Chromium；iPhone Safari 和贴吧手机 App 的登录会话不能直接交给这个扩展使用。
- 只读取当前账号在浏览器中正常能访问的贴吧页面。遇到登录失效、验证码、风控或访问限制时停止，不尝试绕过。
- 百度贴吧页面结构可能变化，搜索结果选择器需要随贴吧页面更新维护。
- 扫描结果是需求候选，不代表每条都是真实、有效或可承接；仍需人工筛选。
- 寻找需求目标（作品、书籍、电影等）由需求雷达的寻源工作台完成，候选必须进一步核验，不能将搜索摘要直接标成已找到。
- 不会自动给贴吧用户发私信；沟通与交付由用户本人完成。
