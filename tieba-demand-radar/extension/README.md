# 贴吧需求雷达采集助手（Chrome 扩展）

## 功能
在你自己的 Chrome 浏览器中使用已登录的百度贴吧会话，按吧名和关键词搜索帖子，读取帖子标题和正文，筛选求助需求，并将新需求自动同步到云端需求雷达网页。不会读取、保存或上传百度密码、Cookie、验证码。

## 安装（只需一次）
1. 下载本分支 ZIP：`https://github.com/cenj ie947-droid/mediabot1/archive/refs/heads/tieba-demand-radar-v1.zip`（请去掉链接中的空格；或直接从仓库下载）。
2. 解压，在 Chrome 地址栏打开 `chrome://extensions`（扩展程序）。
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压后的 `tieba-demand-radar/extension` 文件夹。
5. 在同一个 Chrome 浏览器打开贴吧并正常登录。
6. 点击工具栏的「贴吧需求雷达采集助手」，设置贴吧名称与关键词，点击「开始扫描已登录贴吧」。
7. 扫描结束后，扩展会自动打开或刷新需求雷达网页并同步新需求，不需要手动导出/导入。导出 JSON 仅作为备份选项。

## 使用网页端
需求雷达地址：`https://tieba-demand-radar.onrender.com/`。网页端需求保存在当前浏览器设备本地；建议定期在「设置与备份」导出备份。

## 重要限制
- 采集器是桌面 Chrome 扩展；iPhone Safari 和贴吧 App 的登录会话不能直接交给该扩展。
- 只读取当前账号在浏览器中正常可访问的页面。遇到验证码、登录失效、风控或访问限制时停止，不绕过。
- 贴吧页面结构可能变化；如页面选择器变化，采集需要更新。
- 采集内容是待筛选需求，不保证每条都是真实有效客户。
- 寻源使用千帆模型分析线索并搜索公开网页。单个搜索摘要或关键词重合不会直接判为「已找到」；结果会显示证据、冲突与待核验点。候选仍需打开来源核对版本与可获取性。
- 不会自动给贴吧用户发私信；联系和交付由用户本人完成。
